Xᴅ Fʟᴀsʜ Bot v2
================

1. Install Node.js 20+.
2. Extract the ZIP.
3. Run: npm install
4. Edit config.js and change OWNER_NUMBERS.
5. Run: npm start
6. Scan the QR using WhatsApp > Linked devices.

The bot uses Baileys. For group moderation, make the bot a group admin.
Anti-link/media protections depend on the bot having permission to delete messages.
